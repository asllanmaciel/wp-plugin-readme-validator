# Security Policy

## Supported versions

Somente a versão mais recente publicada recebe correções de segurança.

## Reporting a vulnerability

Não abra uma issue pública para vulnerabilidades. Use o recurso **Report a vulnerability** na aba Security do repositório ou envie uma descrição para `contato@asllanmaciel.com.br`.

Inclua o impacto, passos mínimos para reprodução e, quando possível, uma sugestão de correção. Não inclua dados pessoais, tokens ou plugins privados.
