# Código de Conduta

Queremos uma comunidade aberta, respeitosa e acolhedora para pessoas de qualquer nível de experiência.

## Comportamento esperado

- Seja respeitoso, objetivo e paciente.
- Critique ideias e código, nunca pessoas.
- Ajude novos colaboradores a entender o contexto.
- Respeite privacidade, autoria e diferenças de opinião.

Assédio, discriminação, intimidação, exposição de dados pessoais e comunicação deliberadamente hostil não serão tolerados.

## Aplicação

Comportamentos inadequados podem ser reportados de forma privada para `contato@asllanmaciel.com.br`. Os mantenedores poderão editar ou remover conteúdo e limitar a participação quando necessário para proteger a comunidade.
