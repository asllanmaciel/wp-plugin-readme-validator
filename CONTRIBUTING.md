# Contributing

Obrigado por ajudar a tornar a publicação de plugins WordPress mais segura e previsível.

## Antes de começar

- Procure uma issue existente ou abra uma proposta curta antes de mudanças grandes.
- Para uma primeira contribuição, escolha uma issue com `good first issue`.
- Nunca inclua credenciais, plugins privados ou dados reais nos fixtures.

## Desenvolvimento

```bash
composer install
composer check
```

O projeto suporta PHP 8.1 a 8.4. Mudanças de regras devem incluir fixtures válidos e inválidos, além de testes que expliquem o comportamento esperado.

## Pull requests

Mantenha cada PR focada em um problema. Descreva a motivação, o comportamento alterado e os comandos usados para validar a mudança.
